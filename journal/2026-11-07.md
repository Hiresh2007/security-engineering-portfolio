## Problems encountered

- `gh` was not authenticated. Resolved in-session with device-flow login; the first push was rejected because the token lacked the `workflow` scope (needed to push `.github/workflows/*`), fixed with `gh auth refresh -s workflow`.
- 3 tests failed initially: Scapy tried to resolve a host interface to fill
  default MACs for `ARP()` (no Npcap on Windows). Fixed by setting MACs in fixtures.
- A `slots=True` dataclass returns slot descriptors for class attributes; the
  CLI read defaults from the class. Caught in review before running; fixed.
- Demo showed open ports 22/80 but not 443; cause was the demo scanning only
  1–100. The detector was right; the demo was extended.
